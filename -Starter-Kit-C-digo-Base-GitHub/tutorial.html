GUIA RÁPIDO

Como editar o painel

O site é feito com HTML, CSS e JavaScript. Siga este guia para atualizar textos, locais de coleta e aparência.

1. Abra os arquivos do projeto

Abra a pasta do projeto no seu editor de código, como o Visual Studio Code. Os arquivos principais são:

  • index.html: título, descrição e botões de filtro do painel.
  • js/app.js: lista de locais de coleta e funcionamento dos filtros.
  • css/style.css: aparência do painel principal; css/tutorial.css: aparência deste guia.

2. Altere título e textos

No arquivo index.html, procure o texto dentro de <h1> para mudar o título e o texto dentro de <p> para mudar a orientação exibida na página.

Edite somente o conteúdo entre as tags, mantendo as tags HTML no lugar.

3. Adicione ou atualize um local

No começo de js/app.js, cada objeto dentro de LOCAIS_COLETA representa um local. Copie um objeto existente e atualize seus dados:

  • nome: nome do ecoponto ou ponto de coleta.
  • bairro: bairro ou região.
  • categoria: tipo de resíduo aceito.
  • horario: dias e horários de atendimento.
  • mapaUrl: endereço para abrir o local no mapa.

Ao copiar um objeto, mantenha as chaves e as vírgulas entre os campos e os objetos. Um erro de sintaxe pode impedir que os cartões apareçam.

4. Mantenha os filtros em sincronia

As categorias usadas em categoria no arquivo js/app.js precisam corresponder ao valor dos botões em index.html. Por exemplo, para usar a categoria Vidro, escreva exatamente Vidro nos dois arquivos. O botão “Todos” já mostra todos os locais.

Para criar uma nova categoria, adicione um botão seguindo o padrão dos existentes e use o mesmo nome nos locais correspondentes.

5. Personalize as cores e teste

No início de css/style.css, altere as variáveis --verde-principal e --fundo-pagina para mudar as cores principais do painel. Para personalizar a guia principal edite css/style.css. Depois, salve os arquivos e abra ou atualize index.html no navegador.

Confira os filtros, os cartões e os links do mapa. Se algo não aparecer, verifique se os nomes das categorias são iguais e se não faltam aspas, chaves ou vírgulas.
